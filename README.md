# razorblaze18.github.io

Portfolio of Mudit Dhangar, product designer in Vancouver.

Live at https://razorblaze18.github.io

- `index.html`: home page and project index
- `work/`: one case study per project
- `css/site.css`, `js/deck.js`: shared styles and the slide mode

Press **P** on any page to present it as slides. Arrow keys move, Esc exits. Add `?present` to a page address to open it straight into slides.

`.well-known/` holds a Tesla Fleet API public key. Leave it in place.
