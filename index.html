how I work.

AI writes most of the code. The decisions stay mine.

  1. 01Design the flow

    What the person sees at each step, and the real rules behind it.

  2. 02Write the spec

    Screens, rules and edge cases, written so a coding agent can follow them.

  3. 03Build with Claude Code

    It writes most of the code from the spec. I review every change.

  4. 04Test it like a user

    I walk the real flow end to end. King Pins has 38 test files.
