How I work.

AI writes most of the code. The decisions stay mine.

  1. 01Design the flow

    I map what the person sees, step by step, and the rules behind each screen.

  2. 02Write the spec

    Screens, rules and edge cases go into a written spec that a coding agent can follow.

  3. 03Build with Claude Code

    Claude Code writes most of the code from that spec. I review every change before it ships.

  4. 04Test it like a guest

    I walk the real flow end to end and back it with tests. King Pins has 38 test files.
